周易　第二十九卦

坎

坎下坎上

  • 易經：
    • 習坎：有孚，維心亨。行有尚。
    1. 初六：習坎，入坎窞，凶。
    2. 九二：坎有險，求小得。
    3. 六三：來之坎坎，險且枕，入坎窞，勿用。
    4. 六四：樽酒簋貳，用缶，納約自牖，終咎。
    5. 九五：坎不盈，祗既平，咎。
    6. 上六：係用徽纆，寘叢棘，三歲不得，凶。
  • 彖曰：
    • 習坎，重險也。水流而不盈，行險而不失其信。維心亨，乃以剛中也。行有尚，往有功也。天險不可升也，地險山川丘陵也，王公設險以守其國，坎之時用大矣哉！
  • 象曰：
    • 水洊至，習坎；君子以常德行，習教事。
    1. 習坎入坎，失道凶也。
    2. 求小得，未出中也。
    3. 來之坎坎，終功也。
    4. 樽酒簋貳，剛柔济也。
    5. 坎不盈，中未大也。
    6. 上六失道，凶三歲也。
